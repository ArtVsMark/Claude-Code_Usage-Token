# CLAUDE.md — claude-code-usage

Правила для агентских окон, работающих над этим проектом.

> **Правил здесь мало намеренно.** Из
> [Stepik-Python-Grader](https://github.com/ArtVsMark/Stepik-Python-Grader)
> перенесено только то, что вытекает из **среды** — агентских окон, GitHub и
> лимитов. Ни одного правила, выстраданного чужой предметной областью:
> правило без своей истории не соблюдается, оно просто занимает место.
> Остальные появятся, когда их породит собственный инцидент.

## 🎭 Роли

Проект измерительный, и роли здесь другие, чем в продуктовом.

| Роль | Отвечает за | Ключевой вопрос |
|---|---|---|
| 📐 **Метролог** | точность замера, калибровку шкалы, честность выводов | «на чём основана эта цифра и какова её погрешность?» |
| 🔐 **Хранитель данных** | приватность замеров, отсутствие секретов, границу код/данные | «что из этого нельзя показывать никому?» |
| 🏛 **Архитектор** | устройство хранилища, инварианты, границы проекта | «не переоткрываем ли мы решённое?» |
| 🔧 **Разработчик** | реализацию | «работает ли это в обоих окнах — локальном и облачном?» |
| 🧪 **Тестировщик** | проверяемость на подделанных данных | «как это падает, если реестр вернул мусор?» |
| 🧠 **Методист** | документацию, паритет русской и английской витрин | «поймёт ли это человек, пришедший со стороны?» |
| 📦 **Релиз-инженер** | выпуск, версии, публикацию | «что увидит тот, кто поставит пакет?» |

**📐 Метролог — главная роль проекта.** Инструмент, который показывает
неверную цифру уверенным тоном, хуже отсутствующего: по нему принимают
решения. Любое утверждение об остатке обязано называть, из чего оно получено и
насколько ему можно верить.

---

## 📐 Правила измерения

Специфика проекта, которой нет больше нигде.

- **Не выдавать оценку за факт.** Пока шкала не откалибрована, инструмент
  говорит «расход такой-то, остаток неизвестен», а не рисует проценты из
  воздуха. Первые недели он честно бесполезен — и должен это сообщать.
- **Калибровка требует событий, а не времени.** Шкала строится по
  переключениям светофора `allowed → warning → rejected`. Не было переключений
  — нет шкалы, сколько бы замеров ни накопилось.
- **Замер — снимок, а не истина.** Реестр сессий отдаёт то, что знает на
  момент запроса; расход завершившейся сессии может дописаться позже. Считать
  окно закрытым сразу после последнего замера нельзя.
- **Погрешность называется вслух.** Сколько замеров легло в оценку, когда был
  последний, сколько калибровочных точек — это часть вывода, а не отладочная
  информация.

## 🔐 Данные

- **Замеры живут в приватном `claude-code-usage-dat`.** В этом репозитории —
  только код, тесты и документация. Смешивать нельзя: код станет публичным,
  данные — никогда.
- **Путь к хранилищу — в конфиге, не в коде.** Посторонний человек должен
  поставить инструмент и направить его в своё хранилище, ничего не правя.
- **В замер попадает только расход и состояние лимитов.** Ни токенов, ни
  ключей, ни содержимого сессий, ни названий задач. Проверять перед коммитом,
  а не после.

## 🚦 Работа с GitHub

- **GraphQL не использовать.** Все операции — по REST. Одна GraphQL-операция
  стоит ~300 points из 5000/час, REST-запрос — 1 из 5000. Разница в 300 раз, и
  она уже дважды выжигала квоту в соседнем проекте.
- **Мержим по одному.** Первым — то, что чинит красный `main`; пока он красный,
  остальное не мержится вовсе: проверки пройдут на сломанной базе.
- **Метки на PR обязательны:** зона (`area/*`), тип, и связь с задачей —
  `Closes #N` либо явная строка `Без issue: <причина>`.

> **Конвейера здесь пока нет.** В соседнем проекте PR открывает и мержит
> автоматика — ветки `agent/**`, метки `merge-when-green` и `hold`, очередь
> мержей. Сюда эти механизмы **не перенесены**, и до переноса правила про них
> писать рано: правило без механизма — обещание, а не гарантия.

## 🇷🇺 Язык

- **Внутреннее — по-русски:** описания коммитов, тела PR и issue, docstring'и,
  комментарии, тексты ошибок.
- **Витрина — на двух языках:** `README.md` (русский, источник истины) и
  `README.en.md` (перевод). Расхождение по смыслу — ошибка перевода, а не два
  разных утверждения.
- **От внешнего участника русский не требуется.** PR и обсуждение на
  английском принимаются как есть; русские артефакты создаёт мержащий.
- Английским остаётся синтаксис: типы Conventional Commits, идентификаторы,
  имена файлов и флагов.

## 🪟 Окно живёт 3–5 дней

Дальше — перезапуск с передачей эстафеты: цена одного и того же результата
растёт вместе с возрастом окна, потому что каждый ход перечитывает весь
накопленный контекст.

Эстафета передаётся **ссылками на issue, а не пересказом** — иначе проблема
переезжает вместе с ней.

---

## 📐 Инварианты — не переоткрывать

1. **Сервера нет и не планируется.** Хранилище — git: распределённый,
   версионированный, доступный из любого окна. Сервер добавил бы точку отказа
   и потребовал бы согласия на сбор чужих данных.
2. **Остаток измеряется, а не запрашивается.** Внутренние лимиты недоступны.
3. **Замер делает окно.** Данные живут в реестре сессий (MCP), а не в GitHub —
   workflow в Actions туда не достучится.
