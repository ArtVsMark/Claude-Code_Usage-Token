Команда `sample`: снимает замер и дописывает его в приватное хранилище. Реестр
берётся из выгрузки, которую делает окно (MCP процессу Python недоступен),
транскрипты читаются с диска. Готовность хранилища проверяется до первой записи
— включая строку `merge=union`, без которой конфликт приходит не при первом
запуске, а через несколько замеров. Путь задаётся переменной
`CLAUDE_CODE_USAGE_STORE` или флагом `--store`, частота по умолчанию 15 минут.
