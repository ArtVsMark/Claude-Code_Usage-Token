Гейт разметки PR больше не пропускает нетронутый шаблон: подсказка `Без issue: <причина>` внутри HTML-комментария шаблона засчитывалась связью с задачей, и готовый PR без связи проходил обязательную проверку. Комментарии теперь срезаются до разбора, а заглушка вместо пояснения («<причина>», «что именно» в любой разметке) пояснением не считается. Найдено аудитом ответов каталогу (#139).
Гейт кодировки подпроцессов судит по импортам файла, а не по последнему звену имени: вызов через псевдоним (`from subprocess import run as …`) больше не проходит мимо, а своя функция с именем `run` не объявляется находкой. Разбор общий с гейтом дедлайнов.
Ссылка на набор вопросов витрины сверяется целиком, а не началом адреса: `[x](.rules/showcase.json.old)` больше не засчитывается ссылкой на набор.
Объявленный исход «не отработал» больше не остаётся пустым обещанием: проверка набора требует, чтобы каждая константа `EXIT_*` использовалась. Выпуск отвечает третьим исходом на отсутствующее или нечитаемое колесо, гейт UTF-8 — на дерево без скриптов; две константы без настоящего исхода убраны.
